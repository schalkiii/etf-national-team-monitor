# 国家队 ETF 资金监控

以交易所每日登记份额为基础，跟踪核心宽基 ETF 的资金动向，并对「国家队是否在买」给出带证据边界的估算。覆盖 2020-01 至今，含完整牛熊与多轮护盘周期。

**在线报告**：https://schalkiii.github.io/etf-national-team-monitor/

报告每个交易日更新一次（工作日盘后）。份额由交易所 T+1 披露，当日傍晚可查 T 日数据；两融余额同样 T+1，次日运行自动回补。

## 报告包含什么

| 图表 | 回答的问题 |
|---|---|
| 合计份额 · 上证指数 · 国家队增减持估算 | 一级市场大额申购留在了哪里，估算净买入的累计轨迹如何 |
| 申购落点 | 资金流向哪些指数（科创/小盘 vs 大盘蓝筹） |
| 份额结构与 N 日轮动 | 某宽基减少、另一宽基同步增加 = 换仓还是整体撤离 |
| 单基金详情 | K 线、跟踪指数与份额日增量（折算日差分已作废） |
| 当日净申购居前基金 | 每只基金的五灯判定与异常程度 |
| 两融余额 | 杠杆出清/回归的宏观背景 |
| 信号热力图 | 逐日 × 逐基金的方向信号，点格子可看当日判定依据 |
| 市场热度 | 两市成交额 60 日滚动分位，冷清或过热 |
| 数据覆盖台账 | 近 15 个交易日各数据源是否齐全，断档一眼可见 |

## 数据来源与口径

| 数据 | 来源 | 披露节奏 |
|---|---|---|
| ETF 份额 | 上海/深圳证券交易所登记份额（经 akshare） | 日度，T+1，傍晚可查当日 |
| K 线与成交额 | 腾讯行情公开接口 | 日度，收盘后即出 |
| 两融余额 | 交易所两融日度披露 | 日度，T+1 |
| 季度持仓锚点 | 基金定期报告前十大持有人 | 季度，人工录入 |

**份额是正确的基础序列**：二级市场买卖只改价格、不改 ETF 总份额；只有一级市场申赎才改变份额。因此份额跳增证明有人大额申购，但不证明是谁。

**归因需要三个证据合流**：官方公告、季报前十大持有人（滞后约一个季度）、行为特征吻合（回撤期、多宽基同步、量级匹配）。项目只在证据合流时给出估算，并始终标注为估算，不冒充真实持仓。

**归因系数 θ**：季报披露的国家队持仓变化除以同区间总份额变化。θ>1 表示国家队增持超过总增量（同期有其他投资者净赎回）。θ 是区间估计，不是逐日真值。

**活跃日判定**：仅当核心宽基总净申购进入历史 90 分位，或指数跌幅超过 1% 且出现净申购时，才标记为国家队活跃日并按 θ 折算；其余交易日记零。静默日不估算、不冒充。

**口径诚实**：估算值永不冒充真实值；数据不足标 BLOCKED，不降级为中性；分档阈值（如五日 +7.5% / +2% / −2%）只用于描述性比较，不构成预测。

## 五灯信号

每只基金每日由五个维度投票，同色 ≥3 盏判为共振：

| 灯位 | 红灯（风险） | 绿灯（机会） |
|---|---|---|
| 价格位置 | 收盘价在近 250 日分位 ≥80% | 分位 ≤20% |
| 份额流向 | 当日 Δ份额×净值 在近 300 日分位 ≤5%（极端净赎回） | ≥95%（极端净申购） |
| 指数回撤 | — | 跟踪指数当日跌 ≥1.5%（护盘语境） |
| 市场热度 | 两市成交额 60 日分位 ≥80%（过热） | ≤20%（冷清） |
| 融资杠杆 | 融资余额 5 日变化率 ≥+1% | ≤−1% |

灰灯表示中性区间或数据缺失。点热力图任意格子可展开当日 five-lights 判定依据（指标值、判定理由、净申购）。

## 回测实证

基于 250 个交易日、4500 个信号（截至 2026-11-06）：

- **机会共振信号后 20 日平均 −3.3%，胜率 38%** —— 护盘期买入接近「接下落的刀」，左侧布局需分批。
- **SHORT｜中 20 日胜率仅 31%** —— 空头置信度上限设为「中」有数据支撑。
- **LONG｜高（24 例）20 日 −20.2%** —— 高确信多头信号集中在恐慌顶点，是唯一需要回避的信号档。
- 事件研究：7/13 百股跌停后，核心宽基份额 +38%，官方护盘足迹可被份额数据直接观测。

## 已知边界

- 深交所份额接口单次查询上限约 185 自然日，查询已自动分段。
- 部分宽基历史上有拆分/折算，采用资产守恒法（(1+Δ份额)×(1+Δ价)≈折算比 且复权价连续）识别，折算日与披露噪声日的差分作废，原始披露值永不修改。
- 季度锚点是唯一不自动更新的输入，季报披露后需人工更新，报告会标注锚点期数。
- 两融数据自 2022-11 起可得，更早日期该灯位为数据不足。
